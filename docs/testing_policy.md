# テスト完了条件

## 完成動画を必ず1本生成する

開発タスクの最終テストでは、単体テストやモックE2Eだけで完了としない。実際のAPI・音声生成・動画合成・最終エンコードのうち、その変更で利用する本番経路を通し、再生可能な `final.mp4` を最低1本生成する。

これは個々の高速な単体テストを毎回重くするという意味ではなく、一連の変更を完了させる前の受け入れテストとして必ず実施する。

確認項目:

1. `final_encoding` まで成功している
2. `final.mp4` が新しい実行ディレクトリに生成されている
3. ファイルサイズが0ではなく、FFprobeで映像・音声ストリームを読める
4. 可能ならブラウザのプレビューでも再生を確認する
5. 最終報告に生成先、動画尺、解像度、使用した実接続/フォールバックを記載する

外部APIのクォータ不足などで本番経路を完走できない場合は、黙ってモック成功へ置き換えず、失敗理由と不足している外部条件を報告する。
