YUKKURI MOVIE MAKER · 操作手順

テーマから全自動で
完成動画を作る

テーマを入力してから、生成開始・進捗確認・完成動画の確認までを順番に説明します。画面を閉じてもサーバー側の生成処理は継続します。

対象: Windowsローカル版 更新日: 2026年7月16日 所要時間: 入力約1分 + 動画生成時間
この手順の流れ
  1. アプリを開く
  2. テーマと全自動を選ぶ
  3. 生成を開始する
  4. 進捗を確認する
  5. 完成動画を確認する
  6. うまくいかないとき
1

アプリを開く

start_yukkuri_movie_maker.bat をダブルクリックします。起動画面にエラーが出ず、ブラウザでホームが開くまで待ちます。

  • ホームの「＋ 新しい動画を作る」を押します。
  • 以前の動画が一覧にあっても、新規作成の内容には混ざりません。
  • ブラウザが自動で開かない場合は http://localhost:3000 を開きます。
2

テーマを入力し「全自動」を選ぶ

「解説したいテーマ」に動画の内容を入力し、「どこまで自動で作りますか？」で「全自動（おすすめ）」を選択します。

  • テーマは「生成AIを安全に使う3つのポイント」のように具体的に書くと、台本の方向性が安定します。
  • 「全自動」は台本・音声・素材・字幕・動画合成・最終エンコードまで進めます。
  • ボタンの表示が「この内容で全自動制作を開始 →」になっていることを確認します。
3

全自動制作を開始する

「この内容で全自動制作を開始 →」を1回押します。プロジェクト作成と同時に生成ジョブが登録され、概要画面へ移動します。

正常に開始できた目印: 「全自動で完成動画の生成を開始しました」と表示され、画面上部に青い生成モニターが現れます。
4

完成まで待つ

生成モニターの「現在」と工程数を確認します。別のタブを見たりブラウザ画面を閉じたりしても処理は続きますが、起動時の黒いウィンドウは閉じないでください。

  • 待機中: 順番が来ると開始します。
  • 実行中: 台本生成、音声生成、動画合成など現在の工程が表示されます。
  • 完了: 「完成動画を見る」から確認・出力画面へ移動できます。
  • 失敗: 失敗工程と再試行ボタンを確認します。原因を直してから該当工程を再実行できます。
5

完成動画を再生・保存する

生成モニターが完了したら「完成動画を見る」を押します。「確認・出力」画面で動画を再生し、字幕と音声、映像の見え方を確認します。

  • 動画プレイヤーで最初・途中・最後を再生します。
  • 字幕と音声のタイミング、音量、画像の切り替わりを確認します。
  • 問題なければダウンロード操作で final.mp4 を保存します。
  • 直したい場合は「台本」「素材」「編集」から修正し、確認・出力画面で再生成します。

うまくいかないとき

開始後に生成モニターが出ない

画面内の赤いエラー表示を確認します。「プロジェクトは作成されましたが、自動生成を開始できませんでした」と出た場合は、ホームから作成済み動画を開いて生成を再試行できます。

待機中から進まない

起動ウィンドウを閉じていないか確認します。設定画面の接続診断でAivisSpeech、利用するAI、Workerの状態を確認してください。

AI接続エラーになる

設定画面で選択モデルに対応するAPIキーを登録し、「実際に接続診断」を押します。設定済みと接続OKは別の状態です。

音声生成で失敗する

AivisSpeechが起動していることを確認します。起動直後は準備に時間がかかるため、数十秒待ってから失敗工程を再実行してください。
